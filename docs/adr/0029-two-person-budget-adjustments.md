# ADR 0029：预算上限双人审批

状态：已实现并验证。

在已有预算调额的周期、版本和余额约束之外增加可选组织策略。默认关闭以保留升级行为。开启后直接调额被拒绝，新项目以零额度建立，再走申请；所有者可显式变更治理策略，变更取消待办并保留原因/版本，不把该配置冒充根管理员也无法关闭的监管控制。

申请固定预算账户、周期、基础额度版本、申请人、额度和原因，24 小时失效，同账户最多一项待办。决定时重检申请人和审批人当前角色及本地账号，不允许自审。批准调用与直接调额共用的内部事务函数，额度、历史、告警、审计与回执一起提交；驳回或撤回不动金融数据。

先串行化成员写入，再取得组织预算审批锁，避免与所有权交接反向取得两位成员行锁；审批不在推理占额/结算路径上。策略启用前的既有客户端和未排空旧服务存在绕过风险，升级必须整体排空后切换。

详见 [预算审批说明](../budget-approvals.md)。策略关闭多人批准、周期审批、部门预算、支付及外部通知另行设计。
