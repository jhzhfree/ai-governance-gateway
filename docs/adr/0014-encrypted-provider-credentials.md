# ADR 0014：页面配置厂商凭证，数据库仅保存密文

状态：已接受，数据库迁移 0013。

在已有真实供应商配置页面提供 API Key 录入/替换，权限沿用独立平台 OIDC 主体。厂商密钥经 write-only HTTPS API 提交，使用独立部署主密钥 AES-256-GCM 加密；AAD 绑定厂商、凭证版本和主密钥版本。主密钥不存数据库，不通过页面配置。正文审计和供应商凭证使用不同命名空间与密钥。

凭证版本 CAS、密文更新与不含秘密的更改事件同事务，防止并发覆盖或无审计写入。路由读取当前凭证，数据库记录优先；解密失败禁止回退环境账号。在途不可变 Route 保留旧凭证。页面不回显、不缓存密钥，输入框提交即清空。

保留环境注入兼容能力；不引入付费探测、明文查看或自动账号切换。多实例必须分发同等主密钥版本，旧版本需覆盖备份恢复周期。没有 KMS SDK 或自动重加密任务，详情见[操作手册](../provider-credentials.md)。
