# ADR 0017：显式本地身份模式与离线初始化

状态：已接受，迁移 0015。

保留 OIDC 默认模式，新增显式 local，避免把开发 IdP 当作生产登录。本地账号由受控 DB 运维 CLI 首次初始化，无默认密码；首次/重置后强制改密。初始化与账号管理串行化，当前管理员禁止自停用/自降权。密码 Argon2id 固定资源参数，账号及未知用户名登录同等限频，密码计算并发受限。

浏览器复用 Cookie/CSRF 基础设施，增加 issuer 绑定和实时账号检查；旧 OIDC/本地会话不可跨模式混用。账号版本/行锁防止改密或撤销与迟到登录竞态。CLI 使用最长两小时的随机管理令牌，服务端只存摘要，不冒充设备准入 Token。

停用账号原子撤销会话、短期令牌与该身份创建的项目密钥；登录密码更新不自动修改其他项目账本。账号及项目密钥审计失败全部回滚。供应商平台管理员仍显式绑定主体，局部组织权限不自动继承本地账号管理权。

JH-SAC/DAS、企业映射和真实安全验收仍依赖实际契约/环境。详见[本地身份手册](../local-identity.md)。
