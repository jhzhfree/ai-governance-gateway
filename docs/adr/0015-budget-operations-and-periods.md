# ADR 0015：预算运营保持账本事实与周期归属

状态：已接受，迁移 0014。

在线调额只修改 limit，不修改 spent/held/既有预留。采用独立追加历史中的 revision，比对当前 period；组织行共享锁及组织→项目账户更新锁与预留顺序一致。新限额不得低于承诺余额，历史/审计失败回滚全部变更。

按 UTC 月份进行显式可关闭自动轮转，后台检查加授权路径补偿，手工切换须比较当前周期并明确确认。新账户只复制上限，旧账户及迟到结算保留；预留锁住组织当前周期，拒绝旧授权快照。创建项目共享组织锁，避免轮转遗漏并发新项目。目标周期已有账户时拒绝覆盖。

不自动退款、不转移不确定占额，不实施预算审批或财务调整。详见[预算与规则操作](../budget-and-keywords.md)。
