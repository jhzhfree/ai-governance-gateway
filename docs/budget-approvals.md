# 预算上限双人审批

“预算管理”支持组织所有者启用预算上限审批。默认关闭，升级保留既有调额方式；开启后组织和项目上限的调整均须申请，并由另一位当前具备组织 owner/admin 权限的成员批准。

## 使用流程

1. 先在成员管理配置第二位管理员，确保本地账号已启用并完成首次改密；OIDC 模式仍依赖企业身份认证与本组织角色，不能据此证明外部目录账号实时状态。
2. 所有者在预算管理填写策略原因并确认，启用“双人审批”。策略变更会取消当前全部待审批申请，历史保留，策略原因和版本可在页面查看。
3. 所有者或管理员在原预算编辑表单填写新上限和原因，提交后显示待审批；此时预算不变，也不冻结资金。
4. 另一位管理员/所有者登录，选择批准、填写决定原因。服务端重新核查双方的当前角色、本地账号状态、有效期、周期、预算版本和已用加占额，全部满足才原子应用额度、告警、预算历史、决定和审计。
5. 自己不能批准自己的申请。申请人可撤回；管理员可驳回。批准/驳回/撤回一旦完成不能再次应用，失败或审计异常不改变预算。

策略由所有者管理，**所有者可以显式关闭策略**并留下原因、版本和审计。这是组织治理配置，不是管理员或数据库所有者都无法变更的强制监管锁；如果需要策略关闭也须多人批准，需另行设计恢复与根权限流程。

## 边界与冲突

- 申请有效期 24 小时，每个组织/项目预算账户最多一项待审批。新申请会取消本账户已过期或旧周期的待办，再建立新记录；页面按 ID 分页，每页 50 项，可刷新。
- 提交时和批准时均检查余额。申请期间新占额可能导致降额无法批准，需要撤回后按最新情况重新申请，不释放或退款既有占额。
- 周期或额度版本变化使原申请失效。月度轮转按既有规则继承上限，不通过旧申请修改新周期。当前策略只覆盖上限调整，不改变周期核定和轮转权限。
- 策略修改取消待审批申请；已批准记录及实际调额不回滚。
- 成员被停用或降权后，其未完成申请仍作为历史/待办保留，不能获得批准；其他管理员可驳回。恢复/重新授权不自动批准，仍需独立复核；24 小时有效期继续计算。
- 审批启用时，直接 PUT 预算接口返回 409 / `budget_approval_required`，包括所有者。新项目必须以 **0 上限** 创建，再申请额度，不能用初始额度绕过控制。控制台读取当前策略并默认填零；旧客户端需按此规则更新调用。
- 不涉及供应商配置、已签发密钥、真实费用重算、部门预算、外部消息通知或资金支付。请求推理的预算占额/结算不会等待人工审批。

## API 与一致性

组织级：

- GET/PUT `/api/v1/organizations/{org}/budget/approval-policy`，PUT：`{enabled, expected_revision, reason}`，只有 owner 可写。
- GET 同路径 `/changes?after=REVISION`，返回策略版本、原因、操作者与时间。

组织预算与项目预算分别使用 `/api/v1/organizations/{org}/budget`、`/api/v1/organizations/{org}/projects/{project}/budget` 作为 BASE：

- GET `BASE/approvals?after=ID`：管理员读取申请与回执，不授予普通项目成员访问权。
- POST `BASE/approvals`：`{period, expected_revision, limit, reason}`。
- POST `BASE/approvals/{id}/approve|reject|cancel`：`{reason}`。

写入仍要求正确 Origin/CSRF，所有 ID 都受组织和预算账户范围限制。申请人及审批人不同的约束也在数据库中检查。当前预算、历史与决定在同一事务提交，预算改变失败不会留下“已批准”的回执。锁顺序为组织成员写入锁、预算审批锁、账号/成员校验、周期及预算账户，协调成员停用/所有权交接与并发决定。正常推理不获取成员写入或审批锁。

CLI/TUI 的既有只读预算与成本查询继续可用；审批写入通过 Web 或上述 API。旧客户端不能使用直接调额绕过已启用策略。

## 部署与验收

按 [Ubuntu 部署流程](deployment/ubuntu-24.04.md) 摘流、排空、备份，使用新二进制迁移至 **0022** 并 `migrate check`，再启动。新增三张审批策略/申请/策略版本表；默认无策略，不改变已有预算、占额、月度轮转或结算。**不得混跑旧服务**：旧版本不检查新审批策略，先排空旧进程再切换。

数据库、审计、备份和导出必须留在中国大陆。测试使用真实临时 PostgreSQL、签名测试 IdP、本地双会话和合成供应商；不能代替企业审批制度、真实外部目录与大陆生产部署验收。
