# 第一部分：A 线 · 自研 V1.0（1.5 个月交付）

## 1.1 目标与口径

**目标**：交付可受控试点形态的 V1.0——单机、非高可用、性能数字待实测。
**口径**：研发净 8.0 人周 + **产品设计改造 1.5 人周**（页面/交互定稿、验收标准冻结）+ 联调与返工缓冲 1.0 人周 ≈ **10.5 人周**，对 6.5 周 × 2 研发 ≈ 13 人周容量留有余量——**此前"1 个月"评估未计入产品设计改造，过于乐观，已上调为 1.5 个月**。实现程度分**完整 / 基础 / 预留**（预留=接口+归期明确，非砍功能）。

> **特别说明（交付边界）**：本期交付的是**产品软件的核心功能**。以下工作**均不在本期范围**，属后续阶段另行排期：**硬件适配**（盒子产物、A/B 分区、镜像、容量实测）、**产品发布**（发布工程、渠道与上线）、**授权管理**（离线许可证、License 服务）、**文档编写**（用户手册、部署手册等）及**其他产品资料**（汇报/报价/培训材料等）。期末仅产出运行必需的最小工程产物：单二进制 + 数据库迁移脚本 + 最小启动说明。

**架构选型**：自研内核（Go 模块化单体 + PostgreSQL；开源项目仅作协议语义与兼容性对照）。

| 自研路线 | 要点 |
| --- | --- |
| 优点 | 1) 治理正确性可证明：预算原子预留/结算、限流租约、审计哈希链同库事务完成；2) 单二进制+单库，适配低资源硬件与离线部署；3) 无上游绑定：版本节奏、漏洞处置、许可证（含 AGPL 类条款）不受制于人；4) 安全审计链自持，合规验收对象清晰 |
| 缺点 | 1) 协议生态兼容面靠自建对照测试逐项累积，短期窄于成熟开源；2) 内核全部代码长期自维护；3) 无开源社区问题库与第三方集成生态可借力 |

若改走"成熟开源底座（LiteLLM、One API/New API、Higress/Kong AI 网关等）+ 定点改造"，本评估不适用，需另行立项评估（底座调研、改造 PoC、许可证合规、资源占用验证）；理论上成本与周期延长，且与所选项目直接相关——**需验证后另行给出**（B 线即为该路线的一次落地评估）。

# 第二部分：B 线 · 成熟底座 OmniRoute 改造（后续产品，另行排期）

## 2.1 定位与底座快照

**定位**：面向开发者/BYOK 的聚合网关——与 A 线企业治理网关是**互补产品线**，目标是"治理内核 + OmniRoute 生态覆盖"，**不占用 A 线人力与排期**。
**底座快照**（公开资料，2026-10）：MIT 许可；TypeScript / Node.js 22–26；存储 SQLite(WAL)+LowDB（可选 Redis/Qdrant/Bifrost sidecar）；375 供应商、1400+ 模型、额度感知自动回退、MCP/A2A、桌面/PWA 控制台；约 79k Star、900+ 贡献者、更新活跃。

## 2.2 成熟底座路线的优点（与自研对照）

| 优点 | 说明 |
| --- | --- |
| 起点高、见效快 | 协议覆盖与客户端兼容现成（数百供应商、上千模型与主流开发工具），自研需逐项累积 |
| 生态跟进成本低 | 供应商适配器与协议演进由社区维护，新品类模型上线通常"升级即得" |
| 生态功能即取即用 | 自动回退、配额聚合、MCP/A2A、桌面/PWA 控制台等社区功能直接复用 |
| 社区问题库 | 疑难问题有先例可查，集成与排障成本低 |
| 许可证可行 | MIT 允许商用改造与销售（仍须核查各依赖项许可） |

**完整治理版对照**（若要求全量供应商生态治理化）：PoC 2–3、数据层 SQLite→PostgreSQL 3–4、治理内核移植 6–8、供应商与路由整合 2–3、控制台与交付 2–3、测试与验收 2–3，**合计 17–24 人周 ≈ 2.5–4 个月**。轻量版省在：只接 3 家国内模型、哈希链/KMS/双人导出后置、终端控制简化档（不做 SDK 代理与企业准入协议）、数据层保留 SQLite。

## 2.4 启动条件与主要不确定点

1. **PoC 第一验证项**：SQLite WAL 上的预算原子性与并发写——不达标需换 PostgreSQL，轻量版上界逼近完整版（17–24 人周）。
2. **点名厂商核对**：要接入的 3 家国内模型若含底座未覆盖的专有网关，每家追加 0.5–1 人周；PoC 前定名单。
3. **双技术栈运维**：Node.js 线与自研 Go 线并存；上游迭代快（版本周更级），fork 需建立补丁管理机制。
4. **产品裁剪**：免费额度聚合等社区功能与商用治理定位的差异，需产品侧在立项时圈定。
