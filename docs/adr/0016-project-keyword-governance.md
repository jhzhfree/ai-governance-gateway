# ADR 0016：项目关键字治理采用确定性有界规则

状态：已接受，迁移 0014。

采用 Go RE2 与字面规则，项目默认关闭。独立策略 CAS 与版本快照、管理审计同事务。命中记录不含正文，每请求/规则/方向去重，失败关闭放行。

输入在派发/预留之前检查。JSON 输出在供应商结算后检查，费用与交付阻断分离；重叠脱敏合并原始匹配区间。SSE 只支持有界 carry 的字面告警；存在输出正则/阻断/脱敏规则时在派发前拒绝流式请求，避免不可撤回内容和协议绕过。没有语义模型、外部护栏调用或动态插件。

告警先形成项目内元数据事件，不冒充外部通知已实现。详见[规则边界](../budget-and-keywords.md)。
