# ADR 0009：共享供应商熔断与项目运行观测

状态：已实现；真实供应商故障演练、生产容量与遥测导出待验收。

## 熔断边界

使用现有 PostgreSQL 保存路由熔断状态，以路由/价格指纹为主键。指纹包含模型别名、供应商、入口、区域、模型、价格及 token 边界，不包含凭证或正文。同一指纹的所有实例和项目共享熔断；不同模型路由相互隔离。部署副本应使用一致的配置与凭证绑定；更换指纹会形成新的熔断域，而不是沿用旧状态。当前不提供在线修改阈值或人工强制关闭接口。

状态机为 closed → open → half_open → closed/open。连续 5 次失败健康观测触发 open，等待 30 秒。下一条通过授权、驻留检查及项目接纳的请求取得唯一探测资格，其他实例返回 503 + Retry-After。探测是该新请求的正常、可能计费的调用，不是后台免费探活，也不重放旧请求；读取状态不触发探测。

数据库行锁串行处理获取与结果更新；generation 隔离旧请求和过期探测的迟到结果，避免旧成功错误关闭新熔断。half_open 租约 180 秒，覆盖接纳后最多 120 秒处理与有界清理；进程退出后下一条请求可在租约到期后替换探测。数据库时钟须稳定，不能只延长处理超时而不调整租约与校验。取消或本地拒绝的探测回到 open 等待，不作为恢复证明。

网络连接失败、超时、HTTP 408/429/5xx、非法协议/用量或未完整结束的 SSE 记为失败；完整且用量有效的供应商响应记为成功，不要求本地财务结算成功才判供应商健康。其他状态（包括普通 4xx/鉴权错误与禁止跟随的重定向）为中性，不增加或重置失败计数；“连续”指排除中性结果后的健康观测。客户端取消、下游写失败和派发前本地失败为中性。多个已在途调用可能继续完成，熔断不会杀死它们；中途关闭的 SSE 仍保留费用不确定性。

熔断检查位于项目接纳后、预算预留前。项目频率窗口会记录这次接纳，但熔断拒绝不建立预算或执行尝试，不联系供应商。熔断数据库获取失败时关闭放行；完成结果更新采用独立 3 秒上下文，失败记 `circuit_update_failed`，不重放已完成业务，探测可依赖租约到期恢复。状态更新、预算和执行元数据是独立提交，不承诺跨模块原子性。

不增加自动重试或跨供应商回退；超时/失败不自动释放预留。原请求必须通过大陆驻留证据检查，熔断恢复不能绕过此检查。mock 不参与供应商熔断，运行界面明确显示为模拟供应商。

## 运行观测

`GET /api/v1/organizations/{org}/projects/{project}/runtime` 复用项目角色授权，推理密钥不能查询。仅返回项目当前授权且通过配置可用性检查的模型的共享状态，不暴露其他项目用量、凭证、供应商原始正文或内部路由键。

同一 repeatable-read 数据库快照返回模型状态、全周期开放预留笔数/金额，以及 unfinished 执行数。金额是项目币种的最小单位十进制字符串，不是可退款金额；账户是否一致仍通过 inspection 核查。未采集执行元数据的历史占额不会冒充 unfinished，仍计入开放预留。

HTTP 请求观测保留在内存，按已授权 org/project 分组，最多 4096 个作用域。超过上限不继续增长；未记录或未被采集的项目 `tracked=false`，未注入监控器时 `instance=null`。快照包含随机实例 ID 与启动时间，重启清零，负载均衡查询可能命中不同实例。这些不是集群总量、持久化审计、账单或吞吐基准。

计数从授权及本地模型/币种校验之后开始；不包含无效参数、未知模型或未认证请求。记录完成的 HTTP 请求数、HTTP 429/503 次数、HTTP 5xx 次数、总耗时和 <=100/500/1000/5000/30000/120000 ms 累计桶，全部请求数也充当 +Inf 桶。耗时包括网关处理/流式输出/清理，不等同供应商延迟或 TTFT。SSE 的错误事件可能保持 HTTP 200，执行结果必须查看持久化 attempt。共享数据库快照和当前实例计数的读取不是一个跨存储原子快照。

采用标准库有界 registry，避免未经使用就引入遥测依赖。持久化多实例指标、Prometheus/OTel 导出、自动告警、TTFT、供应商级关联熔断与保留清理是后续增量，不用当前计数宣称完成生产监控。
