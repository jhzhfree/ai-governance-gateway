# ADR 0006：三家大陆供应商与保守人民币计价

状态：实现与本地集成；真实账号、现价、驻留及生产部署待验收。

用户明确要求至少三家境内供应商，且处理与存储均限定中国大陆。选择阿里云百炼北京、火山方舟北京和智谱国内服务作为三条显式配置路线。前两者有北京 SDK 端点依据；智谱仍须账号及合同级驻留审查，不把域名后缀当作证明。没有国际区、自定义 URL、自动换区、自动重试或跨供应商回退。

以服务端不可变 Catalog 隔离公开别名、物理模型、配置区域、凭证、费率和 token 上界。三家共用受限 OpenAI-compatible 文本 JSON/SSE 核心，profile 处理固定端点和请求差异。凭证仅从固定环境变量读取；配置拒绝未知字段，正常 TLS 校验，拒绝重定向，禁止转发项目令牌/Cookie。保持旧 mock-only 路径独立，避免实调用测试路径混淆。没有引入三套供应商 SDK 或复制其实现。

顶层部署与每条路线要求大陆区域声明、证据编号及到期时间。过期从 Catalog 隐藏、拒绝派发并影响 readiness，在途 context 截止时间也受约束。此为受信任管理员的审查声明，不是程序独立证明第三方内部数据位置；证据不足的账号保持禁用。真实数据不能在尚未核验所在地的开发云环境联调。

数据库追加 0006，仅扩大受管组织币种与模型别名约束。CNY_MICRO 与 MOCK 独立，组织创建后不提供币种修改/转换。API 模型授权同时校验配置 Catalog、组织币种和现有 RBAC，真实项目默认空白名单，项目密钥只可授予项目已有模型。Web 复用 TDesign 授权表单、显式单位与一次性密钥流程，CLI 提供模型目录，TUI 显示授权模型及既有用量/账本。

暂不使用未经验证的 tokenizer。先预留完整已核实输入上界与本次输出上界费用，再按最终合法 usage 和配置费率结算。整数微人民币、big.Int 中间计算、一次向上取整，金额与费率均限制在 JS 精确整数范围。代价是短请求会多占临时额度；收益是没有输入估算低估带来的无依据硬限额承诺。缓存/阶梯/额外服务收费不自动推断，未满足本轮文本计价条件的模型不应启用。

价格指纹绑定单位、端点、物理模型、费率、上界及人工版本，写入现有账本 PriceVersion。部署配置需要归档并在多实例保持一致；尚未引入数据库价格发布与独立账单对账系统。真实供应商违反配置上界、usage 缺失、流式不完整或持久化失败仍保留 uncertain 和占额，不因 HTTP 错误自动退款。

替代方案包括每家独立 SDK、动态 URL 和基于字节的 tokenizer 近似。前者增大依赖及行为差异，第二种增加跨区域与 SSRF 边界，后者不能证明费用上界，均不用于本轮。后续可在各模型真实验收后引入精确 tokenizer、版本化价格发布及完整 attempt 遥测。

运行、来源与明确待验收项见[大陆供应商接入](../mainland-providers.md)。
