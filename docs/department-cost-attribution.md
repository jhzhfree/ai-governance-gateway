# 部门成本归属与历史快照

成本报表现在按**预算入账时的部门路径**增加分组，支持 Web、CLI、终端 UI 和审计 CSV。读取真实账本，不调用供应商、不生成费用、不重算旧账。

## 入账口径

新请求在预算事务中先取得部门配置共享锁，再建立占额与归属记录，提交前不会发生部门配置替换。快照保存当时的完整根到叶部门 ID、名称、父节点与配置版本，和占额、事件原子提交。抓取或写入失败时占额也回滚，不允许缺少新归属记录后继续调用供应商。

幂等重放不覆盖原记录。部门移动、重命名、项目解除归属及晚到结算不会修改已捕获路径；晚到结算仍更新原 UTC 入账日期的金额。程序对归属记录只新增、不更新。数据库管理员的直接数据修改不属于不可篡改或外部锚定保证。

| 状态 | 含义 |
| --- | --- |
| `assigned` | 入账时捕获了部门路径 |
| `unassigned` | 已执行捕获，但入账时项目没有部门归属；路径为空 |
| `historical` | 没有归属记录，例如升级前旧账；路径为空，不根据当前部门补猜 |

归属是**项目成本中心**，不是最终使用人或密钥签发人的所属部门。当前仍不能据此生成可靠的个人费用或员工计费账单。原有结算、估算终结、开放占额、币种与用量覆盖口径保持独立。

## 筛选和权限

原成本报表 GET 与 POST `/export` 支持可选 query：

- `department_id`：按历史路径中的部门 ID 精确匹配，包含当时属于该部门的下级项目。可以查询已删除/已移动部门的历史，不使用当前树反查费用。
- `department_state`：`assigned`、`unassigned` 或 `historical`；省略表示全部。指定部门 ID 时，只能省略状态或选择 assigned。

响应每行增加 `department_state` 和 `department_path`。报表仍按项目、UTC 日期、模型、供应商、币种与路径快照分组，名称变化会保留为不同分组，不将不同历史路径混为当前标签；配置版本只作请求追溯，其他授权变更造成的版本递增不会无意义地拆分成本组。

这些筛选不授予新权限：组织汇总仍仅 owner/admin，项目报表仍按**当前**组织/项目/部门授权检查。历史部门成员不能凭过去的归属继续看已失去项目权限的费用。可重复读事务会锁定部门版本行，拒绝使用等待前的旧权限快照；必要时失败返回 503，重新查询，不放行旧授权。

Web 可输入历史部门 ID或使用结果提供的建议值，并单独选择状态。提交查询后导出使用已提交条件，未提交表单不改变导出范围。CSV 追加部门状态与 JSON 路径列，不改变已有列位置；导出仍先提交审计，失败不发文件。路径含部门名称，文件及副本须留在中国大陆。

```bash
aigw cost-report --org ORG --organization --from 2026-11-01 --to 2026-12-01 --department-id DEPARTMENT_ID
aigw cost-report --org ORG --project PROJECT --from 2026-11-01 --to 2026-11-08 --department-state historical
```

终端 UI 的 `c` 视图显示快照路径或“历史未记录 / 入账时未分配”；筛选使用 CLI 或 Web。最多 90 天、1000 分组和数据库查询 10 秒限制仍适用，增加维度后可能更早触及分组上限，应缩小范围，不截断总额。

## 升级与验收边界

按 [Ubuntu 部署流程](deployment/ubuntu-24.04.md) 摘流、排空、备份，使用新二进制 `migrate up` 至 **0021**，`migrate check` 后启动。迁移仅新增 `request_department_attributions`，不回填任何旧请求，不更改占额与结算。旧版本服务不能继续混跑：它不会捕获部门，后续会表现为历史未记录；先排空旧进程再切换。

部署前的真实历史样本、官方账单、企业目录与大陆生产存储/容量验证仍需要现场验收。测试使用临时真实 PostgreSQL、签名测试身份和合成 TLS 供应商。当前不包含部门预算账户、历史回填、跨部门分摊、目录同步或个人费用归属。
