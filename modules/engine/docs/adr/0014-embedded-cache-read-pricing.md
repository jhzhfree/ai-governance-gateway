# ADR 0014：DeepSeek 原始缓存命中计费

状态：已实现；完整验证结果以根交付跟踪为准。仅单进程受控文本 Chat/Responses，不代表 Messages、图片或真实供应商账单验收。

## 契约与复用

2026-11-08 核对 DeepSeek 官方 [Chat API](https://api-docs.deepseek.com/api/create-chat-completion/) 与[缓存说明](https://api-docs.deepseek.com/guides/kv_cache/)：输入由命中与未命中组成，`prompt_tokens_details.cached_tokens` 如出现应等于命中量。缓存存在不保证具体请求命中。不复制文档示例或上游实现，不内置实时价格。

复用当前价格目录、配置权限/审计、加密凭证、一致快照、预留、`TokenCost` 整数金额算法、原子回执、恢复任务及既有 SDK 接收路径。新代码只补明确的计量契约和投影，不增加第二套账本。

- `NewEmbedded` 只允许 DeepSeek 文本 Chat 的可选 `cache_pricing`。复用配置 DTO 中 `write_per_million` 必须为 0，`write_ttl` 必须为空；这是“不适用”的配置兼容值，不是供应商报告写入量为零。页面只呈现命中费率。其他供应商、Embedding 和旧 native 模式不能借用这一契约，旧 new-api 读/写契约不变。
- 明确要求原始整数 `prompt_cache_hit_tokens` 和 `prompt_cache_miss_tokens`；其和须为 prompt_tokens。重复、负数、小数、null、缺字段、冲突详情拒绝。已知全零命中合法；缺失计数未知。此契约只允许文本 cached/reasoning 详情，音频、预测、服务端工具等额外计费类别拒绝。
- 派发前按最大输入费率预留，结算为 `ceil((未命中×普通输入价 + 命中×命中价 + 输出×输出价)/1,000,000)`；整个请求只向上取整一次。不按字段分别舍入，不按命中率猜测，不自动调官方价格。
- 命中契约参与公开价格版本摘要，与旧平价、新 API 读写契约区分。JSON/SSE 都必须先验证原始完成、持久写事件，再向公共 Chat/Responses 投影明确的 cached_tokens；不制造 cached_creation_tokens。

## 存储、恢复与升级

追加 0034；不改 0032/0033。绑定新增可空冻结命中费率、`deepseek_cache_v1` 协议；事件新增可空命中/未命中投影。约束保证旧协议费率为空，新协议限定 DeepSeek；事件类别成对出现且和为输入。历史平价记录保持 null，不倒推优惠。

Record 保存原始 usage 原字节和 SHA-256。Settle/Recover 重新解析原始数据，核对主计数、命中/未命中列和冻结费率，再在既有账本/回执事务中扣费。配置改价或凭证轮换不重写历史快照。投影损坏保留未知占额并报告冲突，健康事件继续处理；不重放模型请求。

启动继续自动加迁移锁升级，保留显式 check 模式、校验和、结构漂移和失败回滚。升级前先停止旧二进制的接纳和恢复消费者；0034 引入旧版本无法解析的证据格式，不支持旧/新恢复器混跑。需要回退时恢复匹配旧包的备份，不手工删迁移记录或自动降级。

## 管理与统计

管理 API/Web/CLI 显示冻结普通输入、输出与命中价，以及原始命中/未命中计数。缺证据显示“未取得”，回执不改变客户端 outcome 或内容审计结果。

成本 API 新增 `cache_measured_requests`、`cache_read_tokens`、`uncached_input_tokens`。只汇总具有匹配哈希、已消费事件和回执的缓存证据；已记录但未记账不计入覆盖，平价历史不视为零命中。页面展示缓存计量覆盖与已计量数量。现有成本 CSV 列顺序保持不变，缓存新列仅页面/API可见；供应商对账 CSV 仍是既有 7 列，核对总输入/输出和实际金额，不宣称已实现供应商缓存分类账单导入。

## 验证与边界

专项覆盖零/全/部分命中、未知/冲突/重复和附加计费拒绝、一次取整、价格身份与旧模式隔离；真实 PostgreSQL 升级失败回滚、旧账保留、漂移拒绝、恢复投影重验、权限、报表覆盖与账单匹配。新增 24 个 Chat/Responses 治理场景，含预算、设备、撤销、审计、缺原始字段、断流、存储/回执故障；两条 JSON/SSE 实际 SIGKILL 测试重启前改现行费率，仍按冻结旧价恢复且物理调用数为 1。

真实浏览器发布缓存配置、调用、费用证据、报表、窄屏与可访问性；固定 Python OpenAI SDK 3.46.0 验证 Chat/Responses JSON/SSE 的命中量及回执。逻辑备份恢复包含未记账缓存完成事件。准确运行结果与发现问题记录见 [交付跟踪](../../../../docs/v1-delivery.md)。

仍待真实账号核验响应/账单、目标 32 GiB 机器容量和商业分发来源/依赖审查。合成价格仅用于测试，不能作为供应商报价。Messages、缓存写入/TTL、长上下文阶梯、服务端工具及多模态不是本阶段开放范围。
