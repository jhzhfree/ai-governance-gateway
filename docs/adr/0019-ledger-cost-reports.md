# ADR 0019：以账本快照提供分状态成本报表

状态：已实现并验证。

P1 要求真实成本报表。基于逐笔预算账本与不可逆的历史执行元数据读取，采用 Repeatable Read 快照及 UTC 入账日期分组。预算占额、实际结算、估算终结分列，避免把未结请求或缺少 usage 的调用误计为免费。模型/供应商未知时保留 null；金额/token 和使用 PostgreSQL numeric 转十进制字符串，避免 int64 加和溢出与 JavaScript 精度丢失。

组织汇总仅 owner/admin，项目复用现有授权。90 天、1000 分组和查询超时约束资源；超过限制拒绝，不返回部分总额。CSV 使用 POST 及既有 CSRF，导出审计和查询在同事务中，提交成功才输出；转义公式敏感文本。导出失败不改变账本。

Web、CLI 和 Bubble Tea TUI 共用 API，不维护第二套账本或 mock。此阶段不生成官方账单、不提供不可变财务报表，也不依据共享项目密钥推断个人归属。后续组织层级、官方账单与财务调整按独立阶段交付。
