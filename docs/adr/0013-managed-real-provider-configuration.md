# ADR 0013：平台级真实供应商数据库配置

状态：已接受，实现于数据库 0012。

文件配置能够驱动真实推理，但没有可发现的产品入口；默认模拟开发启动也容易被误认为真实供应商已接通。增加供应商管理 API 和 Web，普通启动默认数据库管理真实路由；不内置模型、报价、驻留依据或模拟回复。

配置为平台级共享资源，由部署绑定的精确 OIDC 主体发布；组织管理员不能取得跨组织修改权。不引入未经定义的全局 owner 继承。厂商 API Key 保留在部署秘密环境中，浏览器只见是否注入；配置不接收任意 URL，继续使用固定大陆入口以限制 SSRF 与凭证外发。

配置与发布主体/摘要/快照同事务，revision 乐观比较并用事务锁串行化。发布失败无半配置；新路由获取读取数据库，无配置缓存；在途请求使用不可变 Route，沿用原价格指纹。数据库读取/凭证/证据异常关闭放行。多实例仍须部署同等凭证并逐实例验收。

兼容文件模式保持只读；模拟模式仅显式测试开关开放，正常 make run 和发布清单移除模拟供应商。没有增加自动付费探测、智能路由回退、自动报价或费用重放。

详细启用流程与限制见[供应商管理](../provider-management.md)。
