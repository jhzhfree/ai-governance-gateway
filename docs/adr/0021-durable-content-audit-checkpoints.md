# ADR 0021：转发前的加密审计片段与租约恢复

状态：已实现并验证。

同步审计 MVP 的请求已经落库，但输出最终封存前只在内存。采用同一 PostgreSQL 内的临时加密片段与认证检查点，输出前提交，不新增明文文件、外部消息队列或第二份权威存储。增长前缀只追加，达到上限后只更新摘要；避免每 token 重写整个前缀的写放大。

片段 AES-GCM 密钥与摘要 HMAC 密钥从组织 DEK 按请求和用途分别派生，限制单一组织密钥下大量流式片段的 nonce 消耗。连续序号、片段链和认证元数据共同验证后，恢复重加密为既有 response payload，追加既有 seal 事件。公共 API 格式与审计员权限不变。

5 分钟可续租窗口高于 120 秒请求超时。恢复先锁记录，再重新读取租约，避免候选查询与续租提交间的竞态；只封存过期租约，结果为 incomplete/status 0，不推断已交付或财务状态。正常封存与到期清理原子删除临时正文。旧版没有检查点的 capturing 不伪造恢复。

每片同步数据库往返属于明确的持久性/延迟取舍，性能与硬件容量需另验收。默认仍只对显式开启审计的项目生效；不能宣称异步 spool、物理故障零丢失、KMS、外部锚定或分区运维已完成。
