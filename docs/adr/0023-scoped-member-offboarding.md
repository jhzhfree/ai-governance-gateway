# ADR 0023：组织范围成员停用与显式恢复

状态：已实现并验证。

只调整角色不能完成离职回收：项目密钥是独立凭据，独立审计员权限也不依赖组织角色。为组织成员添加 enabled 与生命周期版本，在同一个事务中停用并回收本组织密钥、项目单独授权、审计员及待接收交接。保留成员行以维持历史与凭据 FK，不物理删除身份。

鉴权直接锁定并读取成员行 enabled，停用更新同一行，借助 PostgreSQL READ COMMITTED 锁等待后的谓词重检阻止迟到签发；不用旁表快照绕过行锁刷新。所有成员/交接/审计授权写入共用组织成员锁。签发者状态还加入密钥解析与模型发现作额外防护。审计失败全事务回滚。

owner 需先交接，不能停用自己或 owner。恢复必须显式选择非 owner 角色，默认开发者；旧密钥与已移除授权不恢复。组织停用与 IdP/本地全局停用相互独立，在途推理按已授权语义继续结算，避免错误退款或重放。

状态历史追加记录与各项回收数量，Web 明确确认；层级、目录同步和组织整体停用继续分阶段交付。不声称停用能撤回已经发送的网络字节或替代外部账号撤销。
