# ADR 0007：有界实例池与原子快照发布

状态：候选执行模块实现与受控治理联调；主程序未切换，数据库自动发布联动待完成。

## 资源与发布

`gatewaybridge.Pool` 实现根 `ProviderExecutor`。`NewPool` 只通过既有 `NewSupplier` 从服务端 Route 创建实例，不接受客户端地址或 SDK 对象。池内凭证不进入 Stats、日志或普通格式化。

调用方用 `Publish(ctx, generation, routes)` 发布一个完整路由集合。generation 必须严格递增；同版本或旧版本拒绝，防止迟到发布覆盖新凭证。它是进程内发布代次，不等同数据库配置 revision，也不是只比较某一供应商的凭证 revision。相同别名和执行身份复用实例。所有新实例创建成功、请求未取消、驻留审查仍有效后，才在锁内整体切换；失败清理暂存资源并保留原集合。空集合停用全部新请求。

`MaxBindings` 同时限制现用、排空、构建中的实例；轮换应预留容量。容量不足直接拒绝本次发布，旧版继续工作，不能强行关闭在途请求或偷偷超配。没有无限历史版本缓存，也没有隐式重新尝试或跨供应商回退。构建和关闭在请求查找锁外完成；发布操作串行化，排队的发布可响应 context 取消；查找/租约操作使用短临界区。

## 租约与关闭

`MaxConcurrent` 是池级全局上限，包括所有供应商、所有版本、JSON/SSE 及尚未消费完的响应体。实例自身限制仍保留；这里不替代根数据库共享准入、组织/项目配额或跨节点限制。

Open 在当前集合上校验 Route 和请求后取得租约；新版本发布后旧快照不能再取得租约。在途请求保持已有不可变实例，旧实例在最后一个租约释放后自动关闭和移除。打开失败、读取结束/错误、显式 Body.Close、请求 context 取消均只释放一次；响应体所有者仍应始终 Close。请求总时限继续由根治理链与传输层负责，池本身不建立独立的强制排空时钟。

Close 停止接纳、取消池及构建 context、等待构建清理、关闭所有实例并等待租约释放；重复/并发关闭安全。即使调用者没有读取响应体，关闭也能通过取消回收。池所有者必须在退出时调用 Close；父 context 取消后也应完成 Close。

## 治理边界与后续

实例池不读写数据库，不处理权限、费用、审计或设备身份。根 Handler 的预算预留、attempt 与派发边界仍在原位，任何未证实用量仍为 uncertain。获得租约不意味着 SDK 可以多次尝试。

本轮不是数据库自动轮换已上线。后续需把配置/凭证读取整合为一致的数据库快照，组合配置与凭证变更生成有序发布代次，定义发布失败时 readiness 和告警，再接入主程序选择开关。不能仅凭看到一个不同的凭证哈希就自动切换，因为迟到的旧 Route 可能反向覆盖新版本。凭证紧急撤销是否取消在途请求也需独立策略，正常排空不等同即时撤销。

## 验证范围

覆盖复用、切换与旧凭证拒绝、排空容量、全局并发、批次失败原子性、过期代次、空集合停用、取消构建、失败 Open、未读响应关闭、并发请求/发布。以本地 DeepSeek JSON 上游核对新旧凭证各执行一次，并完整读取轮换前后响应；不使用真实模型账户。

原 15 个真实 PostgreSQL 治理场景改经池和供应商工厂执行，保留权限/撤销/设备、预算、审计失败、重复/缺失 usage、畸形/超大/断流等门禁。修改测试时发现旧 fixture 仍断言通用 OpenAI 路径和独立测试凭证，已改为精确断言供应商固定路径及受治理 Route 凭证；禁止原生回退断言保留。

完整验证与重复 race 结果见根交付跟踪，不以本地结果宣称容量或生产 HA。
