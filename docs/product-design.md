# 工程分析与产品设计

当前实现与本设计的差异及验收边界见[整体功能覆盖核查（2026-11-04）](functional-coverage.md)。下文最初设计及历史状态不代表所有目标已经落地。

## 1. 已知事实与设计边界

首次分析时仓库仅包含 README，没有源代码、依赖、测试、CI 或数据库模型。本方案是实施设计，不是既有产品的代码审计结论。当前已补充[预算与 SSE 技术原型](prototype.md)及相应测试和 CI 配置，完整业务应用、性能与安全验收仍未完成。

默认面向企业内部开发团队，先支持单组织部署，但所有业务数据保留 organization_id，为后续多组织隔离留出边界。终端 UI 指 TUI；若目标包含移动设备或桌面客户端，需要另立需求。性能指标须在确定硬件、流量和部署环境后通过基准测试确定。

## 2. 产品定位

解决四类问题：模型接入分散、凭证难管理、调用费用不可控、故障与合规问题难追踪。

核心用户与工作流：

| 用户 | 主要任务 | 成功标准 |
| --- | --- | --- |
| 组织管理员 | 配置供应商、成员权限、组织预算 | 凭证不泄露，权限变更可追踪 |
| 项目负责人 | 创建项目、分配额度、管理访问密钥 | 可独立查看项目用量与额度 |
| 应用开发者 | 获取密钥、选择模型、调试请求 | 按文档完成首次成功调用 |
| 运维/审计人员 | 定位失败调用、查阅策略和变更 | 能用 request_id 串联请求、路由与审计 |

最短闭环：配置供应商 → 建立项目 → 授权模型与预算 → 创建项目密钥 → 发起请求 → 查看用量及审计。首次引导围绕这条路径，不要求用户先理解内部模块。

## 3. 首期功能与明确取舍

必须提供：供应商与模型目录、项目及角色权限、一次性展示的项目密钥、模型白名单、限流、预算硬限额、调用记录、成本估算、配置变更审计、Web 和 TUI 管理入口。

模型接入先做一个 OpenAI 兼容供应商。实现 `/v1/models` 和 `/v1/chat/completions` 的非流式与 SSE 文本对话；明确支持字段，对未支持的工具调用、多模态等字段返回结构化错误，避免静默丢弃。其他供应商通过适配器后续增加。

不做首期：Agent 工作流、知识库、插件市场、自动提示词优化、复杂计费结算、跨区域多活。费用是治理估算，不等同供应商账单；币种、单价版本、估算与实际用量分别记录。

## 4. 信息架构与 UI

Web 导航：概览、项目、模型与供应商、访问密钥、策略与预算、调用记录、审计、设置。组织/项目上下文置于固定位置，筛选条件反映在 URL，刷新和分享后仍能还原视图。

关键页面：

| 页面 | 主内容 | 关键交互 |
| --- | --- | --- |
| 概览 | 请求量、成功率、延迟分位数、费用、预算消耗 | 明示统计时间与数据延迟；点击指标进入已筛选记录 |
| 项目详情 | 接入指南、密钥、模型授权、预算与用量 | 按权限展示操作；复制示例时不嵌入真实密钥 |
| 供应商 | 健康状态、模型映射、凭证状态 | 凭证写入后不可回显；连通性检测单独反馈 |
| 调用记录 | 时间、项目、模型、状态、耗时、token、估算费用 | 筛选、分页、详情抽屉与 request_id 复制 |
| 策略编辑 | 作用域、条件、动作、优先级 | 保存前校验；展示影响范围、版本和生效时间 |

参考方向：扣子的工作空间与任务导向引导；腾讯云控制台的信息密度、资源列表和详情组织；腾讯 TDesign 的表单、表格、抽屉、状态反馈与无障碍约定。这些是公开产品的交互借鉴，不宣称使用其内部技术架构，也不直接复制品牌视觉或素材。正式界面开发前，应基于届时官方产品和组件文档复核。

视觉原则：中性色为底、单一主色、状态同时用文字与图标表达；统一间距、字号、圆角和语义色 token。首期优先桌面浏览器，窄屏保留查看与基础操作；复杂表格允许横向滚动。每页必须覆盖加载、空数据、无权限、失败重试和成功状态。

TUI 使用同一资源名称与权限语义，以项目切换、用量查询、调用排障为主；复杂策略编辑优先通过 Web，TUI 首期只读展示。全程可键盘操作，支持搜索、分页、帮助与退出，退出后恢复终端状态。终端宽度不足时自动减少列，禁用颜色时仍可识别状态。另提供非交互 CLI 和 JSON 输出供脚本使用。

## 5. 安全及数据原则

默认不存储提示词和模型回复正文，只存治理元数据。后续若开启正文采集，必须按项目明确授权、脱敏并设置保留周期。日志与追踪禁止出现 Authorization、供应商凭证或完整项目密钥。

角色初定 Owner、Admin、Developer、Viewer；具体操作权限由服务端判定，前端隐藏按钮不是授权机制。项目密钥仅授权推理调用，不授予管理权限。组织隔离、越权访问和凭证撤销必须有自动化验证。

产品上线前仍需确认：组织登录方式、预期流量、首个供应商、部署区域、数据保留要求及团队规模。上述事项不阻塞基础工程和接口契约设计，但阻塞生产发布验收。
