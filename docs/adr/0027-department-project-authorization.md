# ADR 0027：组织内部部门树与项目授权

状态：已实现并验证。

将部门作为组织内部项目分组，沿父节点继承项目角色。使用邻接表与同组织复合外键；项目只绑定一个部门，成员可以多部门授权。祖先授权与项目单独授权取较高角色，保持原有组织角色边界，不新增租户或预算账户。

通过有界完整配置替换与组织配置版本比较，原子更新关系、快照和审计。上限为 100 个部门/8 层、1000 条成员授权/项目归属和 1 MiB 正文；对超过规模的需求另行设计增量 API，避免假装无限伸缩。现阶段共享事务锁保障鉴权稳定，排他锁串行化配置变更；锁顺序为成员写入锁、组织鉴权、部门锁。部门写入不升级组织成员行锁，避免与成员停用形成反向等待。

只允许启用组织成员被授权。停用在相同成员写入锁内移除部门授权、递增配置版本并记录快照；恢复不会复活。部门角色变化遵循原项目角色变更的独立密钥语义，界面要求显式确认；不声称角色撤销等价于旧密钥撤销。

详见 [部门授权说明](../department-authorization.md)。目录同步、部门预算、历史归属报表与审批另行交付。
