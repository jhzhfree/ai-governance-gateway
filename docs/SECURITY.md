# 威胁模型和控制边界

| 风险 | 本轮控制 | 尚需实现 |
|---|---|---|
| 复制服务Bearer Key | 高熵、摘要存储、短有效期、撤销 | 设备mTLS/密钥绑定，当前无法阻止有效Bearer被复制 |
| 伪造租户/主体Header | 身份由凭证服务端映射，忽略来访身份头 | 可信代理和插件元数据签名 |
| 跨租户读取/撤销 | 查询、变更受actor.tenant约束，HTTP及账本测试 | PostgreSQL隔离及完整角色审查 |
| 多请求抢预算 | 数据库写事务和条件预占 | 分布式预算与多层锁序 |
| 同请求重复扣费 | 唯一幂等键及settle一致性 | 跨网关插件事件签名及attempt计费 |
| 上游失败误退款 | pending保留预占，手动核对 | 提供商自动账单对账 |
| 内容泄露 | 固定词输入/输出检测、正文不落盘 | 语义、编码绕过、多模态、完整流式方案 |
| 内部异常/Key暴露 | 错误不透传、响应白名单 | 实际Higress日志审查、诊断脱敏 |
| 请求把URL指向内网 | 不接受调用者URL，配置只指向指定Higress | 运维出口、DNS及完整SSRF策略 |
| 上游重定向泄露Key | fetch redirect:error | 供应商目标白名单与证书策略 |
| 规则拖垮服务 | 仅固定词，消息及响应大小限制 | 有时间界限的安全正则执行 |
| 数据库被篡改 | 事务与文件访问隔离建议 | 加密磁盘、审计外送、追加归档及独立权限 |
| 管理认证长期失效 | 引导凭证仅24小时 | SSO、管理员轮换、恢复和操作审批 |

本版不实现设备健康证明、身份联邦、国密认证或法定合规认证。不收集客户正文作训练。SQLite数据库拥有者可修改账本，因此“append ledger”是应用约束，不能声称具备不可篡改存储。

对外开放之前需要TLS、管理端口隔离、应用限流、SAC/DAS事件签名、完整费用适配、备份恢复演练及独立安全测试。按P1/P2任务交付，禁止将当前研发版直接用于敏感生产业务。

威胁验证关注可证明的行为：伪造主体不得改变归属；已撤销Key不得预占；同一幂等键不触发第二次模型调用；未知费用不得显示为零；安全路由失败不得转向未批准目标。
