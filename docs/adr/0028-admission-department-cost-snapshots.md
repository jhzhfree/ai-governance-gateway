# ADR 0028：入账时部门快照与成本筛选

状态：已实现并验证。

不能把当前项目部门直接连接历史账本：移动或重命名会追溯改变成本，部门删除还会丢失历史标签。为新预算请求在同一事务保存完整路径与配置版本，归属记录仅新增，幂等重放不改写；升级不回填旧账，显式区分已分配、未分配、历史未记录。

预算入账先取得部门共享事务锁，配置写入持有同一排他锁，快照失败回滚占额。配置写入不取得预算账户锁，避免相反锁顺序。报表使用保存路径分组和祖先 ID 筛选；不为当前目录变化重新归类费用，不将入账项目归属冒充最终使用人的归属。

报表当前权限和历史成本归属分开判断。部门鉴权额外锁定配置版本行，使可重复读事务在快照版本已变更时失败，避免仅持有 advisory 锁却使用旧 MVCC 权限。响应与 CSV 保持旧金额字段及精度，CLI/TUI 复用同一 API；导出仍要求原子审计。

详见 [部门成本说明](../department-cost-attribution.md)。部门预算、历史回填、个人成本及跨部门分摊另行设计。
