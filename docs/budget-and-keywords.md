# 预算运营与关键字匹配（0014）

这是 P0/P1 跟踪中的首个功能阶段，不代表整个差距清单已经完成。模块默认不自动轮转、不启用关键字规则；真实供应商、项目密钥和大陆处理/存储约束继续有效。先独立迁移到 0014，再部署匹配版本的后端与 Web。

## 预算管理

导航“预算管理”显示组织（组织 owner/admin）及项目账户。项目预算可由有项目读取权的成员查看，调额仅组织 owner/admin 可执行。金额为整数最小单位；CNY_MICRO 中 1 元 = 1,000,000 微元。

调额要求当前周期、expected_revision、新上限与原因。策略版本独立于请求造成的 spent/held 变化；持有组织→项目账户锁后，用最新已用/占额检查，不能把新上限降到 spent + held 以下。改限额、追加变更历史、管理审计同事务；任一失败全部回滚。旧版本/旧周期/低于承诺余额返回 409，不自动覆盖。

月度自动轮转是组织级配置（默认关），所有项目同步切换。启用后按 UTC 月份检查：网关后台每分钟处理最多 100 个到期组织，首次授权推理也会补做该组织轮转。长时间停机时直接切到当前月，不补建未使用的中间月份。后台失败会重试，授权路径无法完成轮转时拒绝请求，不继续消耗旧周期。

手动切换必须显式确认、带 expected_period，只允许向未来周期前进，并立即生效。新周期复制上限，spent/held 从零开始；目标周期若已经有账户则拒绝，绝不重置已有账户。周期与项目创建/调额通过组织行锁串行化；预留再次核对当前周期，防止旧授权快照在切换后继续预留旧账。

已预留或已派发的请求仍在原周期结算，旧的 uncertain/held 不转移、不退款、不抹除。新旧周期账户与变更记录均保留。此阶段不包含调额审批、预算阈值外部通知或跨周期费用重分配。

接口包括组织及项目 /budget GET/PUT、/budget/changes GET（period 必填，after 版本游标）；组织 /budget/cycle GET/PUT、/budget/period POST。历史每页最多 100 条。

## 关键字策略

导航“关键字匹配”，仅组织 owner/admin 可查看/编辑项目规则和命中记录。规则默认空，最多 32 条，每条 pattern 最多 256 UTF-8 字节；支持区分大小写的字面匹配及 Go RE2 正则。正则不支持环视/回溯引用，最小匹配宽度必须大于零。

| 内容方向 | 支持处置 | 流式边界 |
| --- | --- | --- |
| 输入（逐条 messages 文本） | 告警留痕、阻断 | JSON/SSE 都在派发/预留之前检查 |
| 非流式输出（正文及 reasoning 字段） | 告警留痕、阻断、脱敏 | 阻断优先；脱敏合并原文所有命中区间，避免重叠规则漏掉后缀 |
| 流式输出 | 字面规则告警留痕 | 跨 delta 边界检测，每输出通道最多 255 字节 carry，不撤回已发出的内容 |

只要配置中包含输出正则、输出阻断或输出脱敏规则，流式请求就会在预留之前被拒绝（stream_keyword_policy_unsupported），不能切换到 SSE 绕过策略。需要流式的项目应将输出规则设置为字面告警，或使用单独项目策略。规则不是语义护栏模型，不保证识别变形、编码、图片或工具载荷；协议仍是已支持的纯文本。

输入阻断返回 403 keyword_blocked，不派发、不新增预算占额。输出必须在供应商完成生成后才能检查，因此即便被阻断或脱敏，费用仍按原始 usage 结算；不能因回复被拦截就退款。输出拦截的执行状态与账本已结算状态分别解释。

告警在“关键字命中记录”留痕，此阶段没有自动邮件/Webhook 通知。记录只含规则 ID、策略版本、方向、动作、request_id、时间和作用域，不保存命中片段或正文。每请求/规则/方向只记录一次；流式不逐 token 写日志。策略历史快照单独保留，修改/删除当前规则不抹去历史版本依据。

命中记录失败时关闭放行：输入返回 503；JSON 输出不发送正文；SSE 未开始时返回 503，已开始时发错误且不发 DONE。上游可能已发生费用，保留不确定占额或既有结算，禁止自动重放/退款。脱敏每规则最多处理 4096 个区间，超出则拒绝放行，不截断匹配后假装处理完整。

规则按原文匹配，阻断优先于脱敏。输出脱敏只改交付文本，不篡改 supplier usage。现有内容审计保存规范化请求与网关最终输出；开启输入审计时，原始请求仍按审计策略加密保存。不要将“脱敏交付”误认为“所有审计数据也已删除敏感内容”。规则配置可能本身敏感，应优先使用抽象模式，避免将真实个人信息作为字典项。

接口：项目 /keywords GET/PUT（expected_revision + rules）、/keywords/matches GET（after 为降序 ID 游标，每页最多 100）。写规则、版本快照和管理审计同事务，CAS 冲突返回 409。平台供应商管理员不会因平台身份自动获得其他组织规则权限。

验收：140 个后端顶层测试及 11 个浏览器场景通过；预算币种隔离补充验证通过。覆盖周期并发/迟到结算、审计回滚、输入拦截无占额、重叠脱敏、流式跨片段与留痕故障；未替代真实供应商付费/驻留验收。
