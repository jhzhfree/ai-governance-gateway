# ADR 0018：独立令牌保护的境内 Prometheus 抓取

状态：已实现。

P1 需要部署级指标。现有按项目内存统计在鉴权后开始，无法观察未授权请求，也不提供标准监控协议。

提供默认关闭的 `/metrics`，通过独立部署令牌启用。固定路由类别和 HTTP 状态类别保证低基数，不输出任何租户身份、原文或凭据。鉴权使用 SHA-256 后定长比较，重复 Authorization 拒绝。入口计数与项目统计分开，保持项目隔离和原有管理接口行为。直方图复用既有边界，以秒导出；ResponseController 通过 Unwrap 保持 SSE Flush/写截止时间传递。

Prometheus 主动抓取且完全由部署方在中国大陆运行；网关不配置任意遥测出口。计数仅进程内，监控历史交给境内 TSDB。此阶段不承诺 TTFT、SSE 内容级成功、账单准确性、OTel 或网关数据库历史。后续模块单独设计与验证。
