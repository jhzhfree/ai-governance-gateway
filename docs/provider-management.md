# 真实供应商配置与 AI 网关使用

数据库版本 0013，架构决策 ADR 0013/0014。普通启动使用真实供应商数据库配置，没有内置演示模型、虚构价格或模拟回复。mock 只留在测试入口与合成测试 fixture。

## 此前缺口与本轮实现

此前真实厂商转发已存在，但供应商配置必须由服务器 JSON 文件提供；Web 的“模型授权”只能选择已有模型，不能配置厂商。旧 make run 又默认模拟模式，无法代表真实产品使用。本轮增加“供应商配置”导航、真实状态读取、结构化配置表单、数据库原子发布及运行时加载；该入口无需先创建组织。

真实调用路径为：应用 → 网关 /v1/chat/completions → 项目密钥/模型授权 → 项目限流 → 熔断 → PostgreSQL 预算预留 → 固定厂商 HTTPS 入口 → 规范化 JSON/SSE → 财务结算与执行记录。正文审计按项目显式开启。供应商拒绝、配置失效、凭证缺失或数据库失败不会变成模拟成功。

## 首次部署与授权

1. 构建前后端，独立执行 `migrate up` 与 `migrate check`，升级到 0013。正常运行账号应能读写 provider_configuration/provider_configuration_events/provider_credentials/provider_credential_events，DDL 仍由迁移账号执行。分离账号部署按 Ubuntu 手册设置 default privileges/已有对象授权。
2. 配置 AIGW_DATABASE_URL、HTTPS OIDC issuer、管理 audience、Web origin/client ID，及供应商凭证加密主密钥（见页面凭证手册）。厂商 API Key 可直接通过页面保存，也兼容以下环境变量：AIGW_ALIYUN_API_KEY、AIGW_VOLCENGINE_API_KEY、AIGW_ZHIPU_API_KEY。发布模型涉及哪家，就要求该家的有效格式凭证；未使用供应商可以暂不配置。实际账号权限与付费能力还须真实验收。
3. 将 AIGW_PROVIDER_ADMIN_ISSUER 与 AIGW_PROVIDER_ADMIN_SUBJECT 绑定到指定平台维护人员的真实 OIDC 身份。issuer 必须与登录令牌身份完全一致（包括 realm/路径）；subject 不是昵称、邮箱或组织角色。登录用户可在同源 /auth/session 读取自身 user.issuer/user.subject，勿向外复制 Cookie、csrf 或令牌。
4. 重启以加载部署环境。启动命令为 `bin/gateway --listen 127.0.0.1:8080 --web-dir web/dist`，或已配置好环境后 `make run`。不要传 --mock-only；要在页面编辑时也不要传 --providers。
5. 登录后进入“供应商配置”。未创建组织也可打开。只有指定平台身份看到编辑表单；其他已认证管理用户可看固定服务入口、凭证是否注入、可用模型和配置版本，无法看到内部证据引用或改全局配置。普通组织 owner/admin 不自动拥有平台发布权。

首次没有配置时，页面显示待配置，没有可用模型；推理拒绝，/health/ready 为 503，/health/live 正常，管理 API/页面仍可直接访问。初次配置不要让负载均衡的 readiness 策略切断唯一管理入口；可通过同机反代或运维专用入口完成初始化。未设置平台管理员时只读，不会自动给第一个登录人管理员权。

## 页面操作

表格展示百炼北京、火山方舟北京、智谱国内固定地址。为防止 SSRF/凭证外发，不支持输入任意 Base URL；不能将大陆凭证发往自定义服务器。主机代理、DNS、证书信任与出口仍由部署层控制。

编辑表单填写：

- 部署依据：大陆处理/存储的证据引用和有效期（UTC）；覆盖数据库、备份、密钥系统等。
- 模型路由：供应商、本网关别名、真实厂商模型或方舟 endpoint ID。
- 价格：合同价格版本，输入/输出每百万 token 的微元整数；1 元 = 1,000,000 微元。
- 输入/输出 token 上界：必须匹配账号实际模型能力，预算按完整输入上界保守预留。
- 每模型大陆驻留依据与有效期（UTC）。

新建行不预填价格、模型或证据，必须填写真实值。最多 32 条模型，别名唯一且以供应商 ID 加斜杠开头，如 aliyun/团队别名。只允许已支持的文本协议，不能通过配置解锁工具调用/多模态。价格版本只允许字母、数字、点、下划线、短横线，最长 64 字符。

点击“发布供应商配置”，服务端校验价格、token 范围、证据有效性与所需凭证格式，然后按 expected_revision 事务发布。缺失凭证或不合规配置返回 400，不保存半份配置。过时版本返回 409，刷新后核对最新内容再编辑；其他事务错误返回 503。没有向供应商发“免费探测”或推理请求，保存不会产生模型调用费用。

平台管理员可通过页面密码输入框保存 API Key，后端加密落库，提交后不回显；也可继续使用环境注入。页面状态只表示凭证存储/格式条件，不证明账号实际可调用。数据库凭证优先且无需重启；只有使用环境注入时修改环境变量需要重启。

## 生效与并发

配置和发布事件同事务：事件写入失败时配置回滚。0012 两张表只存非秘密路由、版本、发布主体、摘要和快照；不存供应商 API Key；0013 独立凭证表只保存加密后的密文，事件不记录秘密。全局配置由明确平台身份维护，所有组织共享该目录和部署厂商账号，组织/项目预算、密钥和模型权限继续分隔。

每次获取路由或模型目录都读 PostgreSQL，不使用进程内陈旧配置缓存；同库的多实例看到提交后的配置。每个实例仍需分别注入相应厂商凭证，发布只证明处理发布请求的实例具备凭证格式条件，集群应逐实例检查 readiness。当前保留整份配置原子替换，1–32 个模型；不支持发布空目录或独立“禁用全部”开关。

已获取的 Route 为不可变快照，在途请求继续使用原模型/价格，费用指纹和旧账本不被覆盖。新请求使用新快照；移除模型后目录不再展示，后续推理被拒绝。项目/密钥的历史白名单保留，但不因此恢复已移除路由。价格发布不调整现有预算、费用或占额。

## 让真实应用接入

1. 发布至少一个有效模型，创建 CNY_MICRO 组织和项目。
2. 在项目模型授权中勾选实际需要的别名，再签发受限项目密钥。
3. 应用的 base_url 改为 `https://你的网关域名/v1`，api_key 换成项目密钥，model 使用已授权别名。
4. 先发送无敏感合成文本的 JSON 与 SSE，再用同一 request_id 核对执行、用量、预算及真实账单。三家分别验收，不能把其中一家成功当作全部成功。

```python
import os
from openai import OpenAI
client = OpenAI(
    base_url=os.environ['AIGW_BASE_URL'],
    api_key=os.environ['AIGW_PROJECT_KEY'],
)
response = client.chat.completions.create(
    model=os.environ['AIGW_MODEL'],
    messages=[{'role': 'user', 'content': '网关接入验证'}],
    max_tokens=128,
)
print(response.choices[0].message.content)
```

只支持文本 Chat Completions JSON/SSE 与模型目录，不声称完整 OpenAI SDK 所有功能可用。SDK 的自动重试应根据业务风险关闭或谨慎配置：当前没有客户端请求幂等重放保证，不应在超时或 SSE 已输出后自动再次付费调用。

## 兼容模式与测试边界

`--providers /path/reviewed.json` 保留文件配置兼容模式，页面明确只读；该模式不读取数据库供应商发布行。切换到数据库模式需人工核对并在页面重新发布，不隐式导入/覆盖发布历史。

`--mock-only` 还必须显式设置 AIGW_TEST_MODE=1 才可启动；独立 mock-provider 同样受此限制。make test-run/make run-mock 为测试入口；make run/build/package 的正常路径不启动模拟供应商，普通构建清单与发布包不包含 mock-provider。测试 fixture 仍可用合成 TLS 服务验证真实适配器、预算和审计，不请求真实付费账号。

真实验收仍需你自己的厂商密钥、模型/端点、价格、合同与部署证据。当前没有自动拉取价格、厂商账号发现、任意厂商/端点插件、平台管理员自助分配页、原生 KMS 密钥输入或供应商账单自动拉单；不能将这些目标计为已实现。

完整回归保持默认每包 120 秒。在较慢磁盘/受限环境可显式设置 AIGW_GO_TEST_TIMEOUT=5m 运行同一验证脚本；该选项仅调整测试总时限，不跳过测试或修改产品请求超时。

## 本阶段验证

最终后端完整门禁通过 129 个顶层测试（含 race、真实临时 PostgreSQL、迁移/结构漂移、权限、CAS、审计回滚、单连接池）；冻结依赖、TS 契约、类型/ESLint/Prettier、生产构建及 10 个浏览器场景通过。新增浏览器场景从页面发布新别名，刷新确认持久化，再授权项目、创建密钥并通过该路由调用真实适配器协议。供应商为合成 TLS 测试服务，未使用真实付费凭证，不宣称真实厂商或生产部署验收。
